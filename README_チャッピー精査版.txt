館内ナビ PRIVATE DEV - チャッピー第1次精査版

利用者側に距離や曲がりを入力させず、開発側で概算値を入れる版。

改善:
- 50施設すべてで「現在地補正ポイント → 目的地」の距離を別々に概算
- 現在地を変えると目的地までの概算距離も変わる
- 概算距離から直進/右/左/階移動の案内を自動生成
- 香川県の主要モールは公式ショップ情報で実在店舗を追加
- PRIVATE DEV + noindex のまま

精度表示:
B = 公式ページを個別確認し、階や位置関係を使った概算
C = 公式施設情報と施設規模からの一次概算
綾川イオン = 通路グラフ方式

注意:
公式フロア図は縮尺がないことが多いため、メートル値は実測値ではなく大体の値。
公開前に利用者学習データや施設提供データで補正する設計。
