館内ナビ PRIVATE DEV - バックグラウンド自動補正版 V3

画面から削除:
- 「自動学習モード」
- 「完全自動・みんなの平均距離学習」
- 学習回数・平均距離・データ書き出し等の開発者向けUI

内部では自動:
1. 利用者が目的地をタップ
2. 歩数・推定距離・大きな方向変化をバックグラウンド記録
3. ナビが到着判定したら自動保存
4. 同じルートが3件以上たまると、その平均距離を次回のナビ概算に自動反映
5. 5件以上では極端なデータを除外して平均化

利用者は学習用の入力をしません。

iPhoneの制限:
初回だけ、iOSが「モーションと方向へのアクセスを許可しますか？」という
システム権限確認を表示する場合があります。これはWeb/PWAでは自動回避できません。
許可後は学習専用の操作画面は不要です。

複数ユーザー集約:
AUTO_LEARN_API / AUTO_AVG_API はPRIVATE開発中のため未接続。
サーバーを接続すれば他人の端末の匿名サンプルも同じ平均距離に反映できます。

重要:
PWA版の到着判定はナビの推定残距離0を利用します。
店前ビーコン/UWBによる物理的な到着確認は将来のネイティブ版で追加します。
