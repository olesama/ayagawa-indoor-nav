館内ナビ PRIVATE DEV - 全自動センサー版 V4

変更:
- 画面上の「方位」「歩数」「GPS精度」ボタンを削除
- 目的地を選んだ瞬間に、必要なセンサーを自動起動
- 方位センサーを自動取得
- モーションセンサーを自動取得
- GPS/位置精度をwatchPositionで自動更新
- 歩行検出でナビ残距離を自動で減らす
- これまでのバックグラウンド距離学習も継続

利用者の操作:
目的地を選ぶ → 歩くだけ

iPhoneの制限:
初回だけiOSのシステム権限確認
「モーションと方向へのアクセスを許可しますか？」
「位置情報の利用を許可しますか？」
が表示される場合があります。
これはiPhone側のセキュリティ仕様で、アプリが勝手に許可することはできません。
一度許可すれば、専用の方位/歩数/GPSボタンは不要です。

PRIVATE DEVのまま。公開用にはしていません。
