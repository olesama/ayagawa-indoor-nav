館内ナビ - 完全自動学習版

ユーザー操作:
1. 目的地を選ぶ
2. 普通に歩く
3. ナビが到着判定まで進む
これだけ。途中の右/左入力や到着ボタンは不要。

自動記録:
- 歩数
- 推定距離
- 向きの大きな変化
- 所要時間
- 出発地点
- 目的地

到着時:
- ナビの最終ステップに入ると自動保存
- 同じルートの平均距離を自動再計算
- 5件以上では上下10%程度を除外した平均を使用

他人のスマホを含めて平均する方法:
- server/worker.js と server/schema.sql を使う
- APIを公開したあと index.html の AUTO_LEARN_API に /route-sample のURLを設定
- それまではPRIVATE DEVとして端末内のみ自動学習

重要:
PWAだけでは店前ビーコン/UWBで「物理的に本当に店へ到着した」ことを100%確認できません。
現在はナビの推定残距離が0になった時点を到着として自動保存します。
本番で完全な自動到着判定を狙う場合はネイティブiPhoneアプリ + BLE/UWB等を追加します。
