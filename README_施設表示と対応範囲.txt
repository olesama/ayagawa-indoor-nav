館内ナビ 施設表示修正版（2026年9月23日）

1. イオンモール綾川：1F/2F/3Fの概略図に、登録済みの店舗、トイレ、エレベーター、1Fの入口を表示します。施設名をタップすると試作経路を表示します。
2. 他県を含む50施設：施設名や県名で一覧を検索できます。既存の目的地候補を一覧表示し、各施設の公式案内へのリンクを残しました。
3. 他県の階別図面・トイレ・エレベーター・通路・屋内での現在位置はデータがありません。このため、仮の右左折や概算距離を確定した経路として出さない仕様に変更しました。全国すべての施設の詳細に対応したものではありません。
4. 綾川の図面とマーカーも実際の公式フロアマップを写したものではなく、既存の概算座標による模式図です。施設名称や位置が変わる場合があります。現地で公式案内と照合してからご利用ください。
5. iPhoneでは公開したHTTPSサイトから開くとホーム画面に追加できます。このZIP単体はApp Storeアプリではありません。

他県の施設を詳細に追加する際は、施設ごとに公式フロア図面の利用許可、各階の店舗・設備の位置、通路と階移動、実地での位置確認が必要です。
